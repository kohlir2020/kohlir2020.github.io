RAG Citation Generator for SmartChat™

Rocket Software (2024)

Designed and implemented a novel retrieval-based grounding and citation generation system for SmartChat™, a production RAG assistant, using a Gaussian Mixture Model to dynamically rerank cross-encoder and BM25 similarity scores, yielding 80% more relevant document references.

  • Hybrid retrieval (BM25 keyword search + semantic search) surfaces many candidate documents per query, but not all retrieved documents actually ground the LLM's answer; solved for selecting the correct per-query citation subset without a fixed top-k cutoff.
  • Built the production relevance signal by embedding the generated answer and each candidate document with a bi-encoder and scoring citation relevance via cosine similarity, experimenting with a lightweight local sentence-embedding model as an alternative to the system's default embedder.
  • Added a keyword-similarity signal to counterbalance cases where semantic-only scoring could unfairly penalize documents that were surfaced primarily through keyword/BM25 matching, and evaluated a cross-encoder reranker and a custom natural-language-inference entailment score as additional ensemble candidates before settling on the simpler, better-performing bi-encoder cosine-similarity score for production.
  • Designed an unsupervised cutoff algorithm that fits 1- vs. 2-component Gaussian Mixture Models to each query's similarity-score distribution, using BIC/AIC to detect whether scores are naturally bimodal (relevant vs. irrelevant) or unimodal; falls back to an inflection-point/elbow heuristic when unimodal, and otherwise assigns the higher-mean cluster as "relevant" and validates the split with a silhouette-score quality gate.
  • Engineered separate handling so non-embeddable content (tables, SQL, images, metadata-only documents) bypasses similarity scoring and is always cited, added deduplication for multi-hop citations, and built structured logging to support offline, dataset-driven evaluation.
